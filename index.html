About Me

Hello! I'm Himanshu Raj, a blockchain developer fascinated by decentralization and the idea of building systems that run on trust, code and consensus instead of middlemen.

I work with Solidity and the Ethereum ecosystem to write smart contracts, and pair them with modern JavaScript and React front-ends to ship complete dApps — from the on-chain logic to the interface users actually touch.

I'm constantly learning how Web3 tooling fits together — wallets, contracts, testing and deployment — and pushing every project to be a little more secure and a little cleaner than the last.

"In code we trust."
