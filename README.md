- 🌌 **Animated starfield + glowing orbs** background
- 🪪 **About, Skills, Projects & Contact** sections
- 🧩 **Project cards** linking straight to GitHub repos

## 🚀 Getting Started

Clone the repo and open the file — that's it.

```bash
# 1. Clone
git clone https://github.com/himanshu1306-cyber/portfolio.git

# 2. Move in
cd portfolio

# 3. Open in your browser
# just double-click index.html, or:
start index.html      # Windows
open index.html       # macOS
```

## 🌐 Deploy

### Option A — Vercel (recommended)
1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → **Add New Project**
3. Import this repository → **Deploy**
4. Your site goes live in seconds 🎉

### Option B — GitHub Pages
1. Push the repo to GitHub
2. Go to **Settings → Pages**
3. Set the branch to `main` and folder to `/root`
4. Save — your site will be live at `https://himanshu1306-cyber.github.io/portfolio/`
